TerminusDB 11.1.1-1 is a minor hotpatch released on **4 August 2023**, one day after 11.1.1. It bundles dashboard v6.0.9.

## What it does

Dashboard v6.0.9 brings assorted fixes and one visible addition: you can now properly close a pull request in the UI instead of leaving it open.

**Read more:** [TerminusDB dashboard](/docs/dashboard/)

## Upgrade

```bash
docker pull terminusdb/terminusdb-server:v11.1.1-1
```
