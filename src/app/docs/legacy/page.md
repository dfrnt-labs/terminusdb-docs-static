You may have found this page from an old link or a search result for TerminusCMS, TerminusX or DFRNT Hub. These products are retired. The open source TerminusDB database is unchanged, and it is the product these docs describe.

## What these products were

- **TerminusX** was an earlier hosted service for TerminusDB.
- **TerminusCMS** came after TerminusX. It was a hosted service with a web dashboard for teams, projects and data curation.
- **DFRNT Hub** was the later name of TerminusCMS.

All three are retired. For hosted TerminusDB, see [TerminusDB Cloud](/docs/cloud/). A new modeller ships with TerminusDB 12.1.
