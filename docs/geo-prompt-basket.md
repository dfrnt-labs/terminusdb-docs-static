# GEO Prompt Basket

A fixed set of prompts used to measure how AI assistants answer questions about TerminusDB — whether they mention us, cite terminusdb.com, and describe the product accurately. Run the basket, score the answers, record the results. Trends over time tell us if our generative-engine-optimization work (llms.txt, robots.txt AI crawler policies, product naming) is landing.

## Method

1. **Cadence:** run the full basket once a month, and after any major naming or SEO change.
2. **Engines:** run every prompt on ChatGPT, Claude, Perplexity, and Gemini. Fresh session per prompt — no conversation context.
3. **Score each answer** on three yes/no axes:
   - **Mention** — is TerminusDB named as an answer or option?
   - **Citation** — does the answer cite a terminusdb.com URL (not terminusdb.org, not a mirror)?
   - **Accuracy** — are the claims right (open source Apache 2.0, document graph, WOQL/datalog, git-for-data, maintained by Gettier)?
4. **Record** results in the log table below: date, engine, prompt id, mention/citation/accuracy, and a one-line note on what the engine got wrong.
5. **Review:** if a prompt scores zero on mention across all engines twice in a row, decide whether to add docs coverage for that intent — not just to chase the metric.

## Levers this measures

- `public/llms.txt` and `public/llms-full.txt` — curated and generated LLM-facing content.
- `robots.txt` AI crawler policies — generated by `next-sitemap.config.js` (`robotsTxtOptions`).
- Product naming — one name (TerminusDB) across the site; renames documented on the [What is TerminusDB Cloud?](../src/app/docs/what-is-dfrnt/page.md) page.
